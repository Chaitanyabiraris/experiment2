# 🏎️ SuperCar Showcase Website

A stunning, modern showcase website for supercars featuring interactive elements and responsive design.

## Features

✨ **Modern Design**
- Sleek dark and light theme with gradient accents
- Smooth animations and transitions
- Professional typography and spacing

🏎️ **Featured Supercars**
- Ferrari F8 Tributo
- Lamborghini Revuelto
- McLaren 765LT
- Porsche 911 Turbo S
- Bugatti Chiron Super Sport
- Koenigsegg Gemera

📱 **Responsive Design**
- Mobile-friendly layout
- Adapts seamlessly to all screen sizes
- Touch-friendly interface

🎨 **Interactive Elements**
- Smooth scroll navigation
- Hover animations on car cards
- Interactive gallery with zoom effects
- Working contact form
- Dynamic card animations on scroll

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Advanced styling with gradients, animations, and grid layouts
- **JavaScript**: Interactive features and smooth navigation

## Sections

1. **Navigation Bar** - Sticky header with smooth scroll links
2. **Hero Section** - Eye-catching landing area with call-to-action
3. **Featured Cars** - 6 supercar cards with specs and descriptions
4. **Gallery** - Visual showcase of supercars with hover effects
5. **Contact Form** - Get in touch section with form validation
6. **Footer** - Social links and copyright information

## Color Scheme

- Primary Red: `#FF0000`
- Gold Accent: `#FFD700`
- Dark Background: `#1a1a1a`
- Light Text: `#f0f0f0`

## Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Explore the features and navigate through sections
